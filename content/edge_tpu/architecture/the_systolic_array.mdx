## Building the Array

In order to understand how this structure works for matrix multiplication, this page goes over using a 2x2 Systolic Array for implementing a 2x2 matrix multiplication.
We can see that the Systolic Array is built out of a grid of interconnected PEs as shown below. 

Recall that $a$ flows left to right, and $c$ flows top to bottom

### Tying to Computation

From the above demo, we can see we obtained the values 23 and 21 as the output. So a new question arises. What did we just compute?

Well the first thing we should do is take a look at how the diagram above is structured. The way the weights ($b$) are laid out in a grid visually suggest that the $B$ matrix is as follows

$$
B = 
\begin{bmatrix}
5 && 3 \\
4 && 6
\end{bmatrix}
$$

This is correct, but what about our input? Where was that in the diagram? The answer is the input was the numbers 3 and 2, flowing in from the right. Its important to note that they didnt enter the array at the same time. They were skewed. So this suggests 
our $A$ matrix was one of the two possibilities below:

<Cards>
    <Card title="Option 1">
        $$
        A = 
        \begin{bmatrix}
            3 && 2
        \end{bmatrix}
        $$
    </Card>
        <Card title="Option 2">
        $$
        A = 
        \begin{bmatrix}
            2 && 3
        \end{bmatrix}
        $$
    </Card>
</Cards>

Since the number 3 flows in first, we can define our input to be **Option 1**, thus we just saw hardware perform the computation below

$$
C =        

\begin{bmatrix}
    3 && 2
\end{bmatrix}

\times

\begin{bmatrix}
5 && 3 \\
4 && 6
\end{bmatrix}

=

\begin{bmatrix}
23 && 21
\end{bmatrix}
$$

This means, that in order to do a full matrix $\times$ matrix multiplication, we just feed in another row vector like the one above, just after we feed in the original row vector. In general feeding a matrix $A$ into a systolic array follows this algorithm

```python

# A is some 2x2 matrix made up of elements a00 to a11
A = [
  [ 'a00', 'a01' ],
  [ 'a10', 'a11' ]
]

# decompose the matrix into row vectors
row_vector_one = A[0]
row_vector_two = A[1]

# then the first element of each row vector is appended to a list
pe_00_input = [ row_vector_one[0], row_vector_two[1], 0 ] # padded with 0, so the length matches
pe_10_input = [ 0, row_vector_one[1], row_vector_two[2] ] # starts with 0, because it needs a skew

print(pe_00_input) # output: [a00 , a01, 0]
print(pe_10_input) # output: [0, a10, a11]

```
